# Personal Portfolio

A personal frontend developer portfolio built with HTML and CSS, with Bootstrap and Font Awesome resources. The page introduces my work, highlights the services I offer, and provides ways to get in touch.

## Sections

- **Home** — introduction and frontend developer profile
- **About Me** — background, interests, and contact links
- **Services** — web development, responsive design, performance, UI improvements, and support
- **Contact** — contact form and social links

## Tech Stack

- HTML5
- CSS3
- Bootstrap
- Font Awesome
- Google Fonts (Work Sans)

## Run Locally

```bash
git clone https://github.com/aya-aboelkheir/My_Portfolio.git
cd My_Portfolio
```

Open `index.html` in your browser.
